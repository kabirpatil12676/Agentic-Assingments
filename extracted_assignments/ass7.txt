Task 11: AI Travel Agent
Objective:
Create an AI travel agent that recommends a travel plan based on location, weather, budget, and number of days.
Code:
import os
from dotenv import load_dotenv
from huggingface_hub import InferenceClient load_dotenv()
token = os.getenv("HF_TOKEN") client = InferenceClient(
api_key=token, provider="featherless-ai"
)
location = input("Location: ") weather = input("Weather: ") budget = int(input("Budget: "))
days = int(input("Number of days: ")) prompt = f"""
You are a travel planning agent.
Create a realistic short travel plan for: Location: {location}
Weather: {weather} Budget: ₹{budget} Number of days: {days}
Keep the plan practical and mention approximate spending. """
response = client.chat.completions.create( model="meta-llama/Llama-3.2-1B-Instruct", messages=[{"role": "user", "content": prompt}], max_tokens=150
)
print("\nTravel Plan:") print(response.choices[0].message.content)

Task 13: Interview Question Generation Agent
Objective:
Create an interview preparation agent that selects difficulty based on experience and generates interview questions with short answers.
Code:
from langchain_core.tools import tool
from huggingface_hub import InferenceClient import os
from dotenv import load_dotenv load_dotenv()
token = os.getenv("HF_TOKEN") client = InferenceClient(
api_key=token, provider="featherless-ai"
)
@tool
def difficulty(experience: int):
"""Select interview difficulty based on years of experience.""" return "Easy" if experience < 2 else "Advanced"
years = int(input("Years of experience: ")) level = difficulty.invoke({"experience": years}) prompt = f"""
You are an interview preparation agent.
Generate exactly 3 interview questions for a candidate with {years} years of experience. Difficulty: {level}
For each question:
Give the question.
Give a short, correct answer.
Keep answers to 1–2 sentences.
Make questions relevant to the candidate's experience and difficulty. Use a simple numbered format.
Complete all 3 questions and answers.
Do not add an introduction or conclusion. """
response = client.chat.completions.create( model="meta-llama/Llama-3.2-1B-Instruct", messages=[{"role": "user", "content": prompt}], max_tokens=250
)
print("\nInterview Questions:") print(response.choices[0].message.content)

Task 14: RAG using Embeddings and FAISS
Objective:
Create a basic RAG system that stores college information as embeddings in FAISS and retrieves the most relevant information for a question.
Code:
from langchain_huggingface import HuggingFaceEmbeddings from langchain_community.vectorstores import FAISS
data = [
"College starts at 9 AM.",
"Library is open from 8 AM to 8 PM.", "Exam cell is located in Block A.", "Students must carry their ID cards."
]
emb = HuggingFaceEmbeddings(
model_name="sentence-transformers/all-MiniLM-L6-v2"
)
db = FAISS.from_texts(data, emb)
question = input("Ask college question: ") docs = db.similarity_search(question, k=1) print("\nAgent retrieved:") print(docs[0].page_content)
Output / Result:
Ask college question: Where is the exam cell? Agent retrieved:
Exam cell is located in Block A.
